# 茶叶视频T+7预测分析复盘

> 本模板对齐 `video-analyzing` 的实际流程：八字段内容 → 隔离盲分类和相似度 → schema v4草稿 → 用户确认冻结 → T+7质量门槛 → 九指标与五维复盘 → Observation归池 → 沉淀提案审批。模板用于展示和人工复核，正式数据以不可变Prediction、Review和Observation JSON为准。

## 使用顺序

1. 预测前只提供八字段内容，不得提供当前素材真实商业数据。
2. 每条素材在独立空上下文中完成H/P/S/A/F和匿名候选语义评分。
3. 主流程生成草稿；收到 `确认预测 <draft_id>` 或 `确认预测批次 <batch_draft_id>` 后才冻结正式Prediction。
4. T+7后用正式 `prediction_id` 关联累计真实数据。
5. 未通过质量门槛时停止正式判断，只保存 `insufficient_data`。
6. 通过门槛后生成Review和不可变Observation；样本只是候选，只有沉淀提案获批后才进入新的活动案例库。

## 四、九项指标预测与实际偏差

### 4.1 说明

- `出值概率`：相似案例中该指标产生正值的加权概率。
- `正值区间`：仅在指标大于0时计算的P25–P75区间。
- `undefined`：指标分母条件不成立，不得转换为0。
- 实际值为0时只分析“是否出值”，不与正值区间比较。
- 实际值大于0时，才判断是否低于正值P25、位于区间内或高于正值P75。
- schema v3/v4的点误差使用 `overall_point_prediction`；历史v2使用正值条件P50。
- 当前Review快照中的 `relative_error` 是绝对相对误差：`|预测-实际|÷|实际|`。
- 为了显示预测偏高或偏低，本模板增加辅助字段 `signed_relative_error=(预测-实际)÷|实际|`；正数为预测偏高，负数为预测偏低。该辅助字段不替代当前运行快照的 `relative_error`。
- 实际值为0时，相对误差分母为0，只保留绝对误差和原因。

## 十一、方法说明

1. P25–P75是中间50%分位区间，不要求所有实际值都命中。
2. 单项轻微越界不会自动触发修改建议。
3. Attraction、Conversion使用单指标严重度和Level差判断。
4. Efficiency、Scale、Quality使用多指标联动或Level差判断。
5. 出值概率是否准确，需要在同类Observation中比较预测概率与实际出值率，不能由单条视频下结论。
6. 规则或Pattern修改必须通过Cluster沉淀门槛和人工审批。
7. `sample_pool_action`只表示候选案例方向，不等于已写入活动案例库。
8. 有符号相对误差只用于展示高估/低估；当前运行快照仍保存绝对相对误差。
